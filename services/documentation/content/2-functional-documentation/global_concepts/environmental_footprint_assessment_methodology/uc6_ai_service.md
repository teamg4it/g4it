## How we assess the footprint of an AI Service

G4IT uses the **EcoLogits calculation engine** to assess the environmental footprint associated with AI Services, particularly Large Language Models (LLMs).

For each AI Service imported into an inventory, G4IT calls the EcoLogits `/estimations` endpoint using:

- Provider
- Model
- Output tokens
- Location, when available

The impacts returned by EcoLogits are integrated into the existing G4IT environmental impact calculation workflow.

AI Service impacts are aggregated with impacts originating from infrastructure, physical equipment, cloud services, applications, network and other inventory components.

## Input data used for the calculation

The AI Services import file contains the following information:

| Input | Required | Description |
|---|:---:|---|
| `serviceName` | Yes | Name of the AI Service |
| `provider` | Yes | Provider of the AI Service |
| `model` | Yes | AI / LLM model used by the service |
| `outputTokens` | Yes | Number of output tokens generated by the AI Service |
| `location` | No | Location / electricity mix zone associated with the AI Service |

The following fields are mandatory:

- `serviceName`
- `provider`
- `model`
- `outputTokens`

The `location` field is optional.

The AI Services import is optional when creating an inventory. An inventory can therefore be created without an AI Services file.

## Environmental indicators provided by EcoLogits

EcoLogits currently provides results for only a subset of the environmental indicators managed by G4IT.

The following indicators are currently taken into account for AI Services:

| G4IT indicator | Description |
|---|---|
| GWP | Climate change |
| ADPe | Resource use |
| PE | Resource use, fossils |
| WCF | Water use |

Only the indicators provided by EcoLogits contribute to the AI Service impacts.

## How we allocate impacts to lifecycle steps

The impacts returned by EcoLogits are mapped to the lifecycle steps used by G4IT.

### Usage impacts

Usage impacts are mapped to the **USING** lifecycle step.

### Embodied impacts

Embodied impacts are mapped to the **MANUFACTURING** lifecycle step.

### Distribution

Distribution is included in the manufacturing impact provided by EcoLogits.

Therefore, for the environmental impact criteria provided by EcoLogits, the **DISTRIBUTION** lifecycle step is valued as zero.

It is not considered a data inconsistency.

## Location

The `location` field is optional in the AI Services import file.

When a location is provided, G4IT sends the corresponding location to EcoLogits.

When no location is provided, G4IT sends:

```text
WOR
```

This allows EcoLogits to use the World electricity mix when no specific location is available.

## Unavailable environmental indicators

EcoLogits does not currently provide all environmental indicators supported by G4IT.

When an environmental indicator is not provided by EcoLogits, the corresponding AI Service impact share is considered an **Uncalculated Impact Share**.

This impact share is reported as **Data Inconsistency**, consistently with the existing G4IT data quality principles.

The inconsistency is visible when the **Data inconsistency** filter is activated.

The absence of an indicator from EcoLogits does not prevent the calculation of the indicators that are available.

## EcoLogits calculation errors

An error returned by EcoLogits for an AI Service must not interrupt the inventory calculation.

When EcoLogits returns an error:

1. G4IT captures the error returned by EcoLogits.
2. The corresponding indicator status is set to **KO**.
3. The AI Service result is considered inconsistent data.
4. The error information is included in the exported inventory report.
5. The inventory calculation continues without interruption.

Additional information about EcoLogits warnings and errors is available in the [EcoLogits documentation](https://ecologits.ai/latest/tutorial/warnings_and_errors/).

## Integration of AI Service impacts

The environmental impacts calculated for AI Services are integrated into the overall inventory results.

AI Service impacts are included in:

- Overall inventory impacts
- Contribution analyses
- Multi-criteria views
- Equipment views

### Equipment view

When **Equipment** is selected in the equipment view, AI Services are displayed as a dedicated category for each provider.

The category name follows the format:

```text
[provider] AI services
```

This allows AI Service impacts to be distinguished by provider while contributing to the overall inventory results.

### AI servers

An AI server imported as a physical equipment type is assessed using the existing physical equipment methodology.

AI servers are therefore treated separately from AI Services calculated using EcoLogits.

## Calculation engine

AI Service environmental impact calculations are performed using the **EcoLogits** calculation engine.

## Impact-factor selection

When AI Services contribute to an inventory assessment, the impact-factor selection interface informs the user that AI Services currently provide results only for:

- Climate change (GWP)
- Resource use (ADPe)
- Resource use, fossils (PE)
- Water use (WCF)

All other indicators are treated as uncalculated impact share for AI Services.

The following information is displayed to the user:

> For AI services, only the following factors are taken into account in the calculation: climate change, resource use, resource use fossils, and water use.

## EcoLogits API

G4IT communicates with EcoLogits through the `/estimations` endpoint.

The [EcoLogits API documentation](https://api.ecologits.ai/docs#/Estimations/post_estimations_v1beta_estimations_post) describes the estimation endpoint.

The [EcoLogits API container](https://github.com/mlco2/ecologits-api/pkgs/container/ecologits-api) is used to deploy the calculation engine.
