## Objective

EcoLogits is a calculation engine used by G4IT to estimate the environmental impacts associated with **AI Services**, particularly Large Language Model (LLM) usage.

It complements the existing G4IT calculation engines, such as **numEcoEval** and **Boavizta**, by providing environmental impact estimations for AI Service usage.

EcoLogits calculations are based on information such as:

- AI service provider
- AI model
- Number of output tokens
- Location / electricity mix zone

## What is EcoLogits?

EcoLogits provides environmental impact estimations for the use of AI services and Large Language Models.

G4IT integrates EcoLogits as a dedicated calculation engine so that environmental impacts associated with AI Services can be included in the G4IT assessment workflow.

The EcoLogits API exposes an `/estimations` endpoint used by G4IT to request an environmental impact estimation.

## How does G4IT use EcoLogits?

EcoLogits is deployed as an independent calculation engine within the G4IT architecture.

The general calculation flow is:

1. G4IT identifies the AI Service information required for the calculation.
2. G4IT prepares the parameters required by EcoLogits.
3. G4IT sends a request to the EcoLogits `/estimations` endpoint.
4. EcoLogits calculates the environmental impacts.
5. EcoLogits returns the calculation result.
6. G4IT integrates the result into the AI Service environmental assessment.
7. The result is included in the G4IT calculation output.

EcoLogits is executed independently from the other G4IT calculation engines.

## Information required by EcoLogits

The main information used for an EcoLogits calculation is:

| Parameter | Description |
|-----------|-------------|
| Provider | Provider of the AI service or LLM |
| Model | LLM model used by the AI service |
| Output tokens | Number of tokens generated by the model |
| Location | Geographical location / electricity mix zone associated with the calculation |

The values sent to EcoLogits depend on the information available for the AI Service in G4IT.

## EcoLogits API

G4IT communicates with the EcoLogits API through the `/estimations` endpoint.

The API documentation is available here:

[EcoLogits API - Estimations](https://api.ecologits.ai/docs#/Estimations/post_estimations_v1beta_estimations_post)

The EcoLogits container image is available from the official project repository:

[EcoLogits API container](https://github.com/mlco2/ecologits-api/pkgs/container/ecologits-api)

## Environmental impact calculation

EcoLogits returns environmental impact information associated with the AI Service usage.

The returned calculation is based on the EcoLogits methodology and the parameters provided to the API.

G4IT consumes the returned information as part of the environmental assessment of the AI Service.

## What happens if EcoLogits returns an error?

An error returned by EcoLogits must not cause the G4IT platform calculation to fail.

When EcoLogits returns an error:

1. G4IT captures the error response.
2. The error is associated with the corresponding AI Service calculation.
3. The G4IT calculation workflow continues according to the platform error-handling rules.
4. The error information is made available in the calculation output file.

This keeps failures of the EcoLogits calculation engine isolated from the rest of the G4IT platform.

## EcoLogits deployment

EcoLogits is deployed as a dedicated calculation engine.

The deployment follows the same architectural principles as the other G4IT calculation engines:

- Dedicated Docker deployment
- Dedicated API endpoint
- Independent execution
- Integration with the existing G4IT calculation workflows

The EcoLogits engine can be deployed using the official EcoLogits Docker image or an internally built image derived from the EcoLogits sources.

## EcoLogits version

The EcoLogits version displayed in G4IT corresponds to the version currently deployed in the G4IT environment.

The deployed version is displayed in:

**About G4IT → Useful Information**

When the EcoLogits engine is upgraded, the displayed version must be updated so that the information shown in G4IT corresponds to the version currently running in the platform environment.

## Summary

EcoLogits extends G4IT environmental assessment capabilities to AI Services.

It provides environmental impact estimations for LLM usage based on the AI provider, model, generated output tokens and electricity mix/location.

G4IT communicates with EcoLogits through the `/estimations` endpoint and integrates the returned results into the AI Service environmental assessment.

Errors returned by EcoLogits are handled independently so that an EcoLogits failure does not cause a platform-wide failure.
